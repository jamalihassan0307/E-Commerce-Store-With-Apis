## Overview

Lap Store is a full-stack e-commerce application for laptops and tech products. It includes product browsing, category and brand filtering, cart and checkout flows, order tracking, authentication, and an admin panel for managing products, banners, and orders.

## Highlights

- Clean shopping experience with category and brand browsing
- Product details, cart management, shipping address, and checkout flow
- Login, register, forgot password, and account pages
- Admin dashboard for product listing, editing, banners, and order management
- Dark and light themed UI with a responsive layout

## Tech Stack

- React, Vite, Redux Toolkit, React Router
- Node.js, Express, MongoDB, Mongoose
- Tailwind CSS and shadcn/ui style components
- JWT authentication, Multer, Cloudinary, PayPal integration

## Setup

1. Install dependencies in both `server/` and `client/`.
2. Add your server environment variables in `server/.env`.
3. Run the seed script if you want demo data.
4. Start the backend and frontend with `npm run dev` in each folder.
